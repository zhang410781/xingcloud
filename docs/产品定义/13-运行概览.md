# 运行概览

> 状态：当前已实现

## 1. 产品定位

运行概览是平台整体驾驶舱，与可观测性的监控看板不同：

- 运行概览关注整个运维平台的资产、告警、任务、工单和风险态势。
- 监控看板关注其页面内选择的业务上下文中的 K8S、服务器、数据库、中间件和日志指标。

## 2. 主要内容

当前后端汇总能力包括：

- 资产与 CMDB 概况。
- 告警数量、级别、状态和风险项。
- 任务与计划执行状态。
- 应用发布、事务工单和待审批事项。
- SLA/风险摘要等管理视角数据。
- 各功能页面独立作用域下的业务上下文相关信息。

前端实际展示内容受用户权限、模块开关和是否存在真实数据影响。

## 3. 功能级作用域

平台移除顶部全局业务上下文选择器，改为按功能选择作用域：

- 告警中心、告警规则和巡检计划在页面内选择业务上下文。
- 指标、日志、原生看板和 K8S 管理页在各自页面内选择业务上下文。
- AIOps 智能助手使用会话级业务上下文，不影响其他页面。
- 外部告警不绑定业务上下文，环境展示为 Alertmanager/Zabbix 接入源名称。

这样不同页面可以同时查看不同业务上下文，避免全局切换造成查询范围和告警范围串用。

## 4. 空态

新交付环境没有资产、数据源、告警或工单时显示真实空态，不生成示例资产或虚假统计。

## 5. 当前边界

- 运行概览不是用户自定义 BI 大屏。
- SLA 数据属于平台已有汇总能力，不代表已经实现完整的 SLO 管理产品。
- 概览不替代各专业页面的详细查询和证据。
